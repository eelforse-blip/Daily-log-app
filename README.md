# دفتر اليوم

تطبيق Android لتسجيل ملاحظات يومية، وقائمة "افعل" و"ابتعد عن" بتنبيهات يومية بتشتغل حتى والتطبيق مقفول.

## التثبيت
1. افتح صفحة **Releases** في الـ repo ده من الموبايل.
2. نزّل `DailyLog.apk` من آخر إصدار وافتحه.
3. لو Android طلب، اسمح بـ "التثبيت من مصادر غير معروفة" للمتصفح.

أي تعديل يتعمل push على `main` بيطلّع إصدار جديد أوتوماتيك، وبيتسطّب فوق القديم من غير ما البيانات تضيع.

## البناء محليًا
```
npm ci
npm run sync
cd android && ./gradlew assembleRelease
```
